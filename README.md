# АгроТрак — демонстрационный frontend

Next.js App Router / React / TypeScript. Отдельный прототип, не подключённый к действующему сайту.

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

Откройте http://localhost:3000. Данные каталога и контакты находятся в `lib/data.ts`, маршруты — в `app`, интерактивные компоненты — в `components/UI.tsx`. Избранное и сравнение хранятся в браузере. Формы демонстрационные: заявки не отправляются. Перед запуском необходимо подключить безопасный серверный обработчик заявок, CRM, защиту персональных данных и согласованный юридический текст.

Каталог ограничен примерами, характеристики, цены, наличие, права на фото и логотип требуют проверки. Изображения товаров намеренно заменены нейтральными заполнителями. Фото поля на главной — внешнее иллюстративное изображение Unsplash; перед публикацией необходимо проверить лицензию и заменить на согласованное изображение техники. Это прототип, а не готовый к эксплуатации магазин.

Ограничения: сравнение показывает сохранённые карточки без таблицы характеристик; реальных данных для неё нет. Фильтры ограничены доступными данными; SEO-перенос, карта сайта, canonical и структурированные данные требуют подготовки к запуску. Политика конфиденциальности — заглушка.
