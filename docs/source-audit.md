# Проверка источников

Исходный сайт https://agrotrac.ru/ при автоматическом открытии показал антибот-защиту. Данные контактов и отдельные позиции подтверждены доступными поисковыми результатами и страницами региональных поддоменов. Список товаров является демонстрационным; бренд, комплектация, актуальность ассортимента, сервис и условия требуют проверки. Необходимо получить официальные изображения и разрешение на их использование. Фирменный знак в проекте — временная текстовая надпись, а не оригинальный логотип.
