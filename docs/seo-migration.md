# План SEO-переноса

1. Получить полный перечень URL основного сайта и региональных поддоменов, данные Search Console/Метрики, sitemap и входящие ссылки.
2. Сопоставить каждый старый URL с релевантной новой страницей; проверить товары и категории вручную. `legacy` в `lib/data.ts` содержит отдельные примеры, а не полный перечень.
3. Настроить постоянные 301 только после утверждения карты соответствий. Не перенаправлять всё на главную. Проверить цепочки и 404.
4. Утвердить домен и правила canonical, сформировать sitemap и robots для продакшена. Для регионов проверить реальные различия и стратегию индексации; не использовать hreflang для одинакового языка в городах без обоснования.
5. Сохранить важные метаданные, проверить структурированные данные, индексацию и позиции после запуска. Рабочий сайт не изменён.
